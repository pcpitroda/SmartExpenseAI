Slide 02 / Introduction

Introduction to SmartExpense AI

💡
What is SmartExpense AI?
  • SmartExpense AI is a small AI-based system designed to automatically categorize expenses based on plain-text descriptions.
  • Eliminates manual category selection during daily expense logging.
  • Leverages Tiny AI principles to ensure fast, lightweight, and resource-friendly operation.

Slide 03 / Problem Statement

Challenges in Manual Expense Tracking

✍️
Manual Categorization
Users manually select tags and categories for every single purchase daily, leading to friction.
⏱️
Time-Consuming
Logging transactions individually consumes unnecessary time and leads to user tracking fatigue.
💸
Small Expenses Ignored
Minor daily transactions (coffee, snacks, auto fare) are frequently skipped, distorting budgets.
📊
Unclear Spending Patterns
Unorganized raw transaction data makes it difficult to understand monthly cash flow effectively.
⚠️
Inconsistent Categories
Different tags used for similar items over time create confusing and scattered financial reports.

Slide 06 / How AI Works

How the Tiny AI Engine Works

  1. Transaction Input: User enters expense description text.
  2. Text Processing: Text is cleaned, lowercased, and processed.
  3. Feature Extraction: Important words and key features extracted.
  4. Model Inference: Tiny AI classification model evaluates features.
  5. Category Prediction: System assigns best matching category.
  6. Dashboard Output: Category is displayed instantly on UI.
⚡
Tiny AI Concept
A lightweight classification model is utilized for this concept. It requires minimal memory and computing power, making it ideal for fast, edge-friendly, or client-side execution without massive server overhead.
